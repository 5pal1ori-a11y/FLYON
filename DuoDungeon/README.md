# 듀오 던전 (DuoDungeon)

둘이 함께 내려가는 실시간 협동 2D 로그라이트 iOS 게임입니다. SpriteKit, GameKit, MultipeerConnectivity를 쓰고 iOS 17 이상, 가로 화면에서 돌아갑니다.

## 실행 (Mac과 Xcode 16 이상)

```bash
brew install xcodegen
cd DuoDungeon
xcodegen            # project.yml -> DuoDungeon.xcodeproj 생성
open DuoDungeon.xcodeproj
```

## 게임 규칙

| 항목 | 내용 |
|---|---|
| 조작 | 화면 왼쪽을 누르고 끌면 이동, 오른쪽을 누르고 끌면 그 방향으로 계속 쏩니다 (트윈 스틱) |
| 층 | 7x7 칸 안에 방 7~12개를 무작위로 만듭니다. 시작 방, 일반 방, 보물 방 1개, 보스 방 1개(시작 방에서 가장 먼 막다른 방) |
| 방 | 적을 모두 쓰러뜨려야 문이 열립니다. 장애물 배치는 7가지입니다 |
| 적 | 슬라임(통통 뛰며 추격), 박쥐(지그재그 비행, 바위 통과), 눈알(거리를 두고 사격), 돌진소(준비 동작 뒤 돌진), 보스(원형 탄막, 부채꼴 사격, 슬라임 소환. 체력이 절반 아래로 떨어지면 빨라짐) |
| 능력 | ⚔️ 공격력, ⚡️ 연사, 👟 이동 속도, ✨ 탄환 +1, 🏹 관통, 💖 최대 체력. 보물 방에 3개, 보스 처치 시 1개가 나옵니다 |
| 협동 | 체력이 0이 되면 쓰러집니다. 친구가 1.3칸 안에 2초 동안 서 있으면 체력 절반으로 일어납니다. 둘 다 쓰러지면 게임 오버 |
| 난이도 | 층마다 적 체력이 30% 오르고 적 수가 늘어납니다. 2인 모드에서는 적 체력이 1.5배입니다 |
| 기록 | 도달한 가장 깊은 층을 기기에 저장합니다 |

## 멀티플레이 구조

- **온라인 협동**: Game Center 실시간 매치(`GKMatch`)를 씁니다. 별도 서버가 없고, 친구 초대와 자동 매칭을 지원합니다.
- **근처 협동**: MultipeerConnectivity를 씁니다. 같은 와이파이나 블루투스로 연결하고 인터넷이 필요 없습니다.
- **방장 권한 방식**: 방장이 적, 탄환, 피해, 방 이동을 모두 계산해 초당 20번 상태를 보냅니다. 참가자는 자기 캐릭터 위치, 조준, 발사 여부를 초당 30번 보냅니다. 자기 캐릭터는 각자 기기에서 바로 움직이기 때문에 조작이 밀리지 않습니다.
- **지도 동기화**: 지도는 시드에서 결정적으로 만들어지므로 처음에 시드 하나만 보냅니다.
- **메시지 크기**: 메시지는 직접 바이트로 압축해 1KB 안쪽으로 유지합니다 (`Net/Wire.swift`).

## 파일

```
DuoDungeon/
  App/      앱 진입점, 메뉴·도움말·결과 화면, 화면 전환(AppModel)
  Game/     Core(벡터·난수·층 생성) · World(게임 규칙) · GameController(한 판 진행·통신)
            GameScene(그리기·조이스틱·HUD) · Sprites(코드로 그린 픽셀 아트)
  Net/      Transports(Game Center·근처 연결) · Wire(통신 메시지 형식)
```

## 자동 빌드와 TestFlight

- `.github/workflows/duodungeon-build-check.yml`: `DuoDungeon/` 아래 파일이 main에 푸시되면 시뮬레이터용으로 컴파일만 해 봅니다.
- `.github/workflows/testflight-duodungeon.yml`: Actions 탭에서 **듀오 던전 TestFlight → Run workflow**를 누르거나, `duodungeon-v*` 태그를 푸시하면 실행됩니다.
- 버전은 **3.0**입니다. 빌드 번호는 **40000 + 실행 번호**로, 다른 앱의 빌드 번호(1만·2만·3만대)와 겹치지 않습니다.
- 번들 ID는 다른 앱들처럼 `com.flight.flyon`을 같이 씁니다. 그래서 TestFlight에서 설치하면 폰에 있던 FLYON·구독온·TRADEX·한평상회 테스트 빌드를 덮어씁니다. 따로 두려면 App Store Connect에 새 앱(예: `com.flight.duodungeon`)을 만들고 워크플로와 project.yml의 번들 ID를 바꾸면 됩니다.

## 온라인 협동을 켜려면 (한 번만)

App Store Connect에서 이 앱(FLYON 자리)의 **Game Center** 기능을 켜야 TestFlight 빌드에서 매칭이 됩니다. App ID의 Game Center 기능은 워크플로가 자동으로 켭니다(`CAPABILITIES: GAME_CENTER`). Game Center가 아직 꺼져 있어도 **근처 협동**과 **혼자 하기**는 바로 됩니다.

## 출시 전 확인할 것 (법적 체크리스트)

- **이름 상표**: KIPRIS(키프리스)에서 "듀오 던전"과 "Duo Dungeon"을 검색해, 게임 분류(제9류·제41류)에 같거나 비슷한 상표가 있는지 확인합니다.
- **그림·소리 저작권**: 모든 캐릭터와 타일은 `Sprites.swift`에서 직접 그린 오리지널입니다. 아이템 아이콘은 iOS 기본 이모지를 기기에서 그리는 것이라 파일로 넣지 않았습니다. 다른 게임의 캐릭터, 이름, 그림, 음악은 넣지 않습니다.
- **개인정보**: 서버로 보내거나 수집하는 정보가 없습니다. 근처 연결에는 기기 이름 대신 임의의 이름(`Duo-1234`)을 씁니다. App Store 개인정보 라벨은 "데이터를 수집하지 않음"으로 작성할 수 있습니다. 광고나 분석 SDK를 넣으면 다시 검토해야 합니다.
- **채팅 없음**: 채팅이나 자유 입력 기능이 없어서 욕설 필터나 신고 기능이 필요 없습니다. 채팅을 추가하려면 먼저 검토해야 합니다.
- **등급분류**: App Store 연령 등급 설문에서 "만화 또는 판타지 폭력: 드물게/경미"로 답합니다. 국내 등급분류는 앱스토어 자체등급분류 제도로 처리됩니다.
- **결제를 넣을 경우**: 확률형 아이템을 넣으면 확률을 공개해야 합니다(게임산업법). 아이템 현금 거래나 내기 기능은 넣지 않습니다.
