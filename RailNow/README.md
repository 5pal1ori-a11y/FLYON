# ITGO 잇고

(폴더와 Xcode 타깃 이름은 처음 이름인 RailNow를 그대로 씁니다.)

지하철과 KTX·SRT·ITX-새마을·무궁화호가 지금 어디쯤 달리고 있는지 보여 주는 iOS 앱입니다. SwiftUI와 MapKit을 쓰고 iOS 17 이상에서 돌아갑니다.

## 화면

| 탭 | 내용 |
|---|---|
| 홈 | 즐겨찾는 지하철 노선의 열차 분포, 종류별 운행 중인 기차 수, 곧 다음 역에 닿는 열차 |
| 노선도 | 수도권 전체 노선을 Apple 지도 위에 실제 위치대로 그린 지도. 확대·이동하고 역을 누르면 역 안내가 열립니다. 위쪽 검색창으로 역을 찾습니다 |
| 실시간(지하철) | 노선을 고르면 역을 세로로 늘어놓고, 방향별 선로 위에 열차를 올려 보여 줍니다. 20초마다 새로 받습니다 |
| 지하철 › 역 안내 | 역 이름을 누르면 방향별로 들어오는 열차와 남은 정거장 수가 나옵니다 |
| 지하철 › 경로 찾기 | 출발·도착역을 고르면 갈아타는 순서를 보여 줍니다. 소요 시간은 노선별 평균 역 간 시간과 환승 4분으로 계산한 **추정값**입니다 |
| 기차 | 지도 위에 노선과 열차 추정 위치를 찍고, 아래에 운행 중인 열차 목록을 둡니다. 열차를 누르면 정차역별 시각이 나옵니다 |
| 설정 | 인증키 입력, 데이터 연결 상태, 안내와 출처 |

## 데이터가 어디서 오는가

| 대상 | 출처 | 성격 |
|---|---|---|
| 지하철 열차 위치 | 서울 열린데이터광장 `realtimePosition` | 실시간 수신값 |
| 기차 출발·종착 시각 | 공공데이터포털 국토교통부 TAGO 열차정보 | 그날 시간표 |
| 기차 현재 위치 | 위 시간표로 앱이 계산 | **추정값** (지연 미반영) |
| 역 순서 | OpenStreetMap (korea-mcp 가공본) | 앱에 포함 |

KTX·SRT 같은 간선 열차는 좌표를 주는 공개 API가 없습니다. 그래서 시간표의 출발·종착 시각 사이를 구간 비율로 나눠 위치를 추정하고, 화면에 추정값이라고 표시합니다. 코레일톡이나 SRT 앱의 비공개 통신을 가로채 쓰는 방식은 약관 위반과 법적 문제가 생길 수 있어 쓰지 않습니다.

인천 1·2호선, 김포골드라인, 용인·의정부경전철은 서울시 실시간 API에 없어서 운행 간격으로 만든 미리보기만 나옵니다.

### 인증키가 없으면

인증키가 없으면 앱은 운행 간격으로 만든 **미리보기 데이터**로 돌아가고, 화면마다 "미리보기"라고 표시합니다. 실제 열차 위치가 아닙니다.

인증키는 두 가지 방법으로 넣습니다.

1. 앱의 설정 탭에 직접 입력 (기기에만 저장)
2. GitHub 저장소 Secrets에 `SEOUL_SUBWAY_API_KEY`, `DATA_GO_KR_KEY`를 넣으면 TestFlight 빌드에 포함

키 발급처:

- 서울 열린데이터광장(data.seoul.go.kr) → "지하철 실시간 열차 위치정보" 인증키 신청
- 공공데이터포털(data.go.kr) → "국토교통부_(TAGO)_열차정보" 활용 신청 → 일반 인증키(Decoding)

## 아직 확인하지 못한 것

- 이 코드는 Linux에서 작성했고 실제 기기에서 실행해 보지 못했습니다. GitHub Actions에서 컴파일만 확인합니다.
- 인증키가 없어 두 API의 실제 응답으로 시험하지 못했습니다. 응답 해석은 공개된 명세 기준으로 작성했으므로, 키를 넣은 뒤 첫 실행에서 역 이름 불일치나 필드 차이가 나올 수 있습니다.
- 기차 역 좌표는 근삿값이고 역 사이를 직선으로 잇습니다. 실제 선로 모양과 다릅니다.
- 서울시 실시간 API는 키마다 하루 호출 한도가 있습니다. 사용자가 늘면 앱이 직접 호출하지 말고 서버에서 받아 캐시한 값을 나눠 주는 구조로 바꿔야 합니다. (키를 앱에 넣으면 추출될 수 있다는 점도 같은 이유로 해결됩니다.)

## 실행 (Mac과 Xcode 16 이상)

```bash
brew install xcodegen
cd RailNow
xcodegen            # project.yml -> RailNow.xcodeproj 생성
open RailNow.xcodeproj
```

## 파일

```
RailNow/
  App/        앱 진입점, 탭 구성
  Model/      Subway(노선·열차·노선도 배치·미리보기) · Rail(노선·열차·위치 추정)
  Services/   Services(서울시 API·TAGO API) · TrainStore(화면 상태·새로 고침)
  Views/      Home · Subway · Rail · Settings · Components
  Theme/      색·글꼴·시간 계산
  Resources/  subway.json(역 순서), Pretendard 글꼴
scripts/build_subway.py   OpenStreetMap 기반 자료에서 subway.json을 다시 만드는 스크립트
```

## 자동 빌드와 TestFlight

- `.github/workflows/railnow-build-check.yml`: `RailNow/` 아래 파일이 main(또는 `railnow-*` 브랜치)에 푸시되면 시뮬레이터용으로 컴파일만 해 봅니다.
- `.github/workflows/testflight-railnow.yml`: Actions 탭에서 **ITGO 잇고 TestFlight → Run workflow**를 누르거나, `RailNow/RELEASE` 파일을 고쳐 main에 푸시하면 실행됩니다 (`railnow-v*` 태그 푸시도 가능).
- 버전은 **4.0**입니다. 빌드 번호는 **50000 + 실행 번호**로, 다른 앱의 빌드 번호(1만~4만대)와 겹치지 않습니다.
- 번들 ID는 다른 앱들처럼 `com.flight.flyon`을 같이 씁니다. 그래서 TestFlight에서 설치하면 폰에 있던 FLYON·구독온·TRADEX·한평상회·듀오 던전 테스트 빌드를 덮어씁니다. 따로 두려면 App Store Connect에 새 앱(예: `com.flight.railnow`)을 만들고 워크플로와 project.yml의 번들 ID를 바꾸면 됩니다.

## 출시 전 확인할 것 (법적 체크리스트)

- **공공데이터 이용 조건**: 서울 열린데이터광장과 공공데이터포털 이용약관을 따르고, 앱 안(설정 → 자료 출처)에 출처를 표시합니다. 인증키는 개발자 본인 명의로 발급받고 다른 사람과 공유하지 않습니다. 만 14세 미만은 회원가입에 법정대리인 동의가 필요합니다.
- **비공개 API 금지**: 코레일톡, SRT, 지도 앱 등의 비공개 통신을 분석해 쓰거나 웹 화면을 긁어 오지 않습니다. 약관 위반이고 정보통신망법·부정경쟁방지법(데이터 부정사용) 문제가 될 수 있습니다.
- **상표와 로고**: "KTX", "SRT", "ITX-새마을"은 한국철도공사와 에스알의 등록상표입니다. 앱 안에서 열차 종류를 가리키는 말로만 쓰고, 앱 이름·아이콘·스토어 스크린샷 문구에 내세우지 않으며, 공식 로고나 CI를 넣지 않습니다. 설정 화면에 운영기관과 무관한 비공식 앱임을 밝혀 두었습니다.
- **"실시간" 표현**: 기차 위치는 추정값이므로 스토어 설명에 "KTX 실시간 위치"처럼 쓰면 소비자를 오인하게 하는 표시가 될 수 있습니다(표시광고법). "시간표 기반 추정 위치"로 씁니다. 지하철만 "실시간"이라고 쓸 수 있습니다.
- **OpenStreetMap 자료**: `subway.json`은 ODbL 1.0 자료에서 만든 것이라 출처 표시가 필요하고, 고친 자료를 배포할 때도 ODbL을 따라야 합니다. 이 저장소에 생성 스크립트와 결과물이 공개되어 있습니다.
- **이름 상표**: KIPRIS(키프리스)에서 "ITGO", "잇고"를 제9류·제39류·제42류로 검색해 같거나 비슷한 상표가 있는지 확인합니다. (처음 후보였던 "TAGO"는 국토교통부 국가대중교통정보센터의 서비스 이름이라 쓰지 않습니다. 앱 안에서는 시간표 API의 출처를 밝히는 말로만 나옵니다.)
- **개인정보**: 서버로 보내거나 수집하는 정보가 없고 위치 권한도 쓰지 않습니다. App Store 개인정보 라벨은 "데이터를 수집하지 않음"으로 작성할 수 있습니다. 내 위치 기반 기능, 광고, 분석 SDK를 넣으면 위치정보법 신고 여부와 개인정보처리방침을 다시 검토해야 합니다.
