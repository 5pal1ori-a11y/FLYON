# 등불지기 (Lanternkeeper)

그림자로 싸우는 턴제 퍼즐 로그라이트. iOS용, Godot 4.5로 만들었습니다.

등불을 내려놓으면 나와 기둥과 상자의 그림자가 뻗어 나가고, 그림자에 닿은 적이 쓰러집니다.
내 그림자로 적의 그림자를 밟으면 적이 굳습니다.

## 게임 구성

| 분류 | 내용 |
|---|---|
| 등불 6종 | 촛불, 횃불(화상), 달빛 등(평행 그림자), 쌍둥이 램프, 흔들등(두 번 빛남), 검은 불꽃(빛이 공격) |
| 캐릭터 3명 | 등불지기, 그림자 도둑(그림자 위 순간이동), 새벽 사제(넓은 빛·회복) |
| 구역 4곳 | 안개 정원(시야 제한), 거울 회랑(반사), 잠긴 서고(물길 번짐), 일식의 정상(빛이 줄어듦) |
| 적 | 일반 15종 + 엘리트 변형 5종 + 보스 4종 |
| 방 장치 | 기둥, 상자(밀기), 거울(2차 광원), 유리(파편), 물(그림자 번짐), 화로(그림자 차단·끄기), 거미줄, 어둠, 초, 출구 |
| 방 목표 5종 | 모두 물리치기, 버티기, 등대 지키기, 촛불 의식, 탈출 |
| 각인 60개 | 6개 태그(불꽃·서리·독·연쇄·거울·어둠) × 10, 같은 태그 3개·5개 세트 효과 |
| 유물 40개 | 규칙을 바꾸는 유물 36개 + 대가가 있는 저주 유물 4개 |
| 지도 | 갈림길 지도: 전투·엘리트·이벤트·상점·휴식·보물·보스 |
| 이벤트 30종 | 선택지형 이야기, 갇힌 사람 5명 구출(오두막 시설 해금) |
| 메타 진행 | 등불 오두막 시설 7종, 등불·캐릭터 해금, 이야기 조각 20개, 도감, 그을음 단계(난이도) 15 |
| 매일 콘텐츠 | 일일 도전(전 세계 같은 시드), 주간 도전(주간 규칙 10종 중 2개), 끝없는 탑 |
| 퍼즐 | "한 번의 점화로 모두 물리쳐라" 100문제 (모두 정답이 있는지 자동 검증) |
| 업적 50개 | 등불 꾸미기 8종 보상 (판매 없음) |
| 편의 | 점화 전 결과 미리보기(처치·받을 피해), 되돌리기, 빠른 진행, 색각 보조, 진동, 왼손 모드 |

뽑기, 광고, 현금성 재화, 로그인, 개인정보 수집이 **없습니다.**
그림·효과음·음악은 모두 코드로 직접 생성했습니다(`tools/gen_audio.py`, `tools/gen_icon.py`).

## 폴더 구조

```
scripts/core/   규칙 엔진 (보드, 그림자, 전투, 적 AI, 방·지도 생성, 탐험 상태, 봇)
scripts/data/   콘텐츠 데이터 (적, 등불, 각인, 유물, 이벤트, 이야기, 업적, 퍼즐)
scripts/game/   자동 로드 (Game 진행, Save 저장, Sfx 소리), 루트 화면
scripts/ui/     화면들 (타이틀, 오두막, 지도, 전투, 보상, 상점, 이벤트, 휴식, 결과, 도감, 설정, 도전, 퍼즐)
assets/         글꼴, 효과음·음악, 아이콘, 셰이더
tests/          규칙 엔진 자동 테스트
tools/          퍼즐·소리·아이콘 생성기, 화면 캡처, 자동 플레이 점검
ci/             iOS 내보내기 설정 스크립트 (서명은 저장소 루트의 ci/apple_signing.py)
docs/           TestFlight 설정 가이드
```

## 실행과 테스트

Godot 4.5.1로 폴더를 열고 실행합니다. 명령줄에서:

```bash
godot --headless --path . --import
```
```bash
godot --headless --path . -s tests/run_tests.gd
```

테스트는 그림자 계산, 적 AI, 목표 판정, 방 생성 400개, 지도 생성, 저장·불러오기, 봇 자동 플레이 40방, 퍼즐 100개 정답 검증을 확인합니다.
